# 大阪府警察 通信指令シミュレーター / Osaka City Police Dispatch Simulator

大阪市24区の**実在の道路網・警察署（28署）・交番（約210か所）**を用いた、通信指令（110番受理・部隊運用）と
パトカー運転のシミュレーションゲームです。iPad での操作を主眼に、スマートフォンにも対応しています。

## 主な機能

- **指令台（ディスパッチ）**
  - OpenStreetMap から生成した大阪市の道路網（約14万区間・9.4万交差点、一方通行・信号・道路名つき）上で全車両が走行
  - 110番入電（交通事故・ひったくり・コンビニ強盗・喧嘩・泥酔者保護・DV・暴走行為・特殊詐欺など24種）が時間帯・繁華街に応じて発生
  - 事案ごとに候補部隊を **道路網上の到着予想時間（交通状況込み）** で一覧表示し、部隊・台数・緊急走行の有無・経由地を指令官が選択
  - 指令済み部隊の転進・指令解除・帰署・地点移動・現在地待機・周辺検索、逃走マル被に対する **緊急配備（検問配置）**
  - 事案は経過とともに変化（続報・種別変更・応援要請・逃走・未対応による取消など）
- **部隊**: 所轄PC（各署2〜3台）・自動車警ら隊・交通機動隊（白バイ）・機動捜査隊（覆面）・交番勤務員（自転車）
- **警ら**: 区単位／地図で指定した円／巡回経路（立ち寄り地点）での警ら、重点（繁華街・幹線・住宅街）と実施時間帯の設定
- **無線**: 指令・了解・現着・続報・応援要請・確保・終結などを状況に応じて生成。タップで該当部隊・事案を地図表示。音声読み上げ（任意）
- **運転モード**: 任意の車両を選び運転席視点で操縦。実在の道路・建物（OSM建物 約90万棟）・信号・車線、左側通行の一般車（サイレンで左に寄って停止）、ナビ・ミニマップ・無線表示、現着報告
- ライト／ダークテーマ、折りたたみ式パネル、勤務状況の自動保存

## 操作

- 地図: ドラッグで移動、ピンチでズーム。事案（◆）・部隊（▲）・警察署をタップで詳細
- 左パネル: 事案・部隊・記録 / 右パネル: 詳細と操作 / 下部: 無線（▲▼で拡大縮小）。各パネル端の矢印で折りたたみ
- 運転: 画面左下ハンドル、右下アクセル・ブレーキ（停止中にブレーキ長押しで後退）。キーボードは矢印キー/WASD、H=赤色灯、V=視点、Esc=指令台へ

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm run build      # 本番ビルド (dist/)
npx tsx tests/sim.test.ts 2   # シミュレーションの自動テスト（2時間分）
```

地図データの再生成（Overpass API から取得）:

```bash
node tools/fetch-osm.mjs      # tools/raw に生データを取得（キャッシュ）
node tools/build-data.mjs     # public/data に道路グラフ・施設・建物タイル等を出力
node tools/build-tiles.mjs    # 地図表示用の道路ベクタータイル
```

### 構成

| ディレクトリ | 内容 |
| --- | --- |
| `src/sim` | シミュレーションエンジン（道路グラフ・経路探索、部隊、事案、無線文生成） |
| `src/map` | MapLibre GL による指令地図 |
| `src/ui` | 指令台の UI（一覧・詳細・無線・メニュー） |
| `src/drive` | three.js による運転モード（街路生成、信号、一般車、車両モデル） |
| `tools` | OSM データ取得・変換スクリプト |

地図データ © OpenStreetMap contributors (ODbL)。警察署・交番の名称と位置は OSM に基づきます。
部隊編成・呼出符号・乗務員・事案はすべて架空のシミュレーションです。
